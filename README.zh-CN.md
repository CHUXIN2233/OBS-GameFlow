# OBS GameFlow

简体中文 · [English](README.md)

我会换着玩不少游戏，不想每次都进 OBS 手动选采集窗口，所以做了这个脚本。它会跟着正在玩的游戏切换采集源，Alt+Tab 也不会突然录到桌面。桌面录制和回放缓存也可以按需开关。

[下载脚本](https://github.com/CHUXIN2233/OBS-GameFlow/releases/latest/download/OBS_Game_Follow.lua) · [发布记录](https://github.com/CHUXIN2233/OBS-GameFlow/releases)

## 安装

1. 下载 `OBS_Game_Follow.lua`，放到固定的文件夹。
2. 打开 OBS「工具 → 脚本」，添加这个文件。
3. 确认游戏采集源，按需要打开对应的开关。

三个主要开关默认都是关的。只有一个「游戏采集」源时会自动选；有多个就在「高级设置 → 采集源」里指定。场景和采集源需要自己建，脚本不会帮你创建。

游戏库已经内置，正常使用只需要这一个 Lua 文件，不用额外安装插件或常驻程序。

## 怎么用

- **自动切换**：跟着你正在玩的游戏切换采集源。Alt+Tab 会继续采集原来的游戏；关掉当前游戏后，如果还有其他游戏运行，就切回去。
- **自动回放**：按设置自动开关回放缓存。关掉后仍然可以手动控制；如果缓存已经在运行，关掉这个开关也不会强行停止。
- **录制桌面**：没有游戏时录桌面。有游戏就优先录游戏，不会因为切到浏览器而改录桌面。

开启「自动回放」后：

- **不录桌面**：检测到游戏就开回放，最后一个游戏退出约 5 秒后关闭。
- **录制桌面**：OBS 就绪且桌面采集配置完成后保持回放开启，没游戏时切回桌面。

切换游戏和 Alt+Tab 都不会重启回放缓存。记得先在 OBS「设置 → 输出」里启用回放缓存，并设置保存回放的快捷键。**缓存停止后，没保存的片段就没了。**

## 其他设置

- **桌面**：在同一个场景添加「显示器采集」，放在游戏采集和客户端采集的下方。有多个显示器采集源时，在高级设置里指定。
- **LOL**：给客户端单独加一个「窗口采集」，放在游戏采集上方，再到「高级设置 → 客户端」里选好并开启「采集客户端」。进入对局后会优先采集游戏，退出对局再恢复客户端。
- **没识别到的游戏**：可以在「高级设置 → 游戏库与补充规则」里自己加，一行一条，例如：

  ```text
  mygame.exe=我的游戏
  ```

一般不用折腾游戏库，脚本自带识别规则和排除名单。旧版外部数据路径可以继续用，留空就用内置库。界面默认跟随 OBS 语言，也能手动切换中英文。

需要排查时，在诊断里点「3 秒后检查窗口」，切回游戏，再刷新结果。这里只读取窗口信息，不会乱改采集目标。

目前只支持 Windows。识别到了游戏，不代表 OBS 一定能成功捕获；有些游戏最小化后也会停止渲染。升级时尽量保持原文件名和路径，直接替换脚本，原来的设置就能继续用。

## 可选搭配与致谢

- [Smart Replay Mover](https://github.com/SlonickLab/Smart-Replay-Mover)：把保存的回放按游戏分类、整理文件名。不是必装；如果让 GameFlow 控制回放缓存，记得关掉它的自动启动缓存和保存后重启缓存，避免两个脚本抢着控制。
- [OBS Notifier](https://github.com/DmitriySalnikov/OBSNotifier)：在桌面显示 OBS 的通知，比如回放保存成功。也不是必装。
