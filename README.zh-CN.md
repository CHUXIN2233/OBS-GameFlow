# OBS GameFlow

简体中文 · [English](README.md)

自动识别游戏并切换 OBS 采集源，支持桌面录制和回放自动管理。

[下载脚本](https://github.com/CHUXIN2233/OBS-GameFlow/releases/latest/download/OBS_Game_Follow.lua) · [发布记录](https://github.com/CHUXIN2233/OBS-GameFlow/releases)

## 安装

1. 下载 `OBS_Game_Follow.lua`，放在固定文件夹中。
2. 在 OBS「工具 → 脚本」中添加这个文件。
3. 确认采集源后，按需开启「自动切换」「自动回放」和「录制桌面」。首次添加时三个开关均默认关闭。

游戏库已内置，不用另装 SRM、下载数据库或填写库路径。运行只需要这个 Lua 文件，无需 ASS、Python、WebSocket 或外部常驻程序。

首次使用会自动选择唯一已有的原生「游戏采集」源。没有源时先在录制场景中创建一个；有多个源时，在「高级设置 → 采集源」中选择。脚本不会自动创建场景或采集源。

升级时保持原文件名和路径，替换脚本后重载 OBS 中的原条目。已有设置继续使用，不要同时加载两份自动切换脚本。

## 常用设置

- **自动切换**：跟随正在使用的游戏。Alt+Tab 后保持游戏采集，关闭当前游戏后恢复仍在运行的其他游戏。
- **自动回放**：自动管理回放缓存。默认关闭，关闭时继续切换采集目标，由你手动启停缓存；关闭开关不会停止已经运行的缓存。
- **录制桌面**：没有游戏时录制桌面，游戏优先。缓存是否自动启停由「自动回放」决定。
- **当前采集 / 回放状态**：显示采集目标与缓存的实际开启、关闭状态，点击「刷新」更新。

开启自动回放后的行为：

| 录制桌面 | 缓存管理 |
| --- | --- |
| 关闭 | 检测到游戏后开启，所有游戏退出约 5 秒后关闭。 |
| 开启 | OBS 就绪且桌面采集配置有效后开启；游戏优先，没有游戏时回到桌面。 |

游戏切换和 Alt+Tab 不会重启缓存。在 OBS「设置 → 输出」中启用回放缓存，并设置保存回放快捷键。停止缓存会丢弃未保存的片段。

录制桌面需要把「显示器采集」源加入当前场景，放在游戏和客户端采集源下方；只有一个可用源时可自动选择，多个源时请手动指定。

## 游戏库与规则

内置库包含 11,054 个不同显示名称、13,023 条匹配规则和 348 条忽略规则。名称可能包含别名，不等同于独立游戏数量。库随脚本版本更新，运行时不联网获取数据。

在「高级设置 → 游戏库与补充规则」中可以补充规则，每行一条：

```text
mygame.exe=我的游戏
```

手动规则优先。原来的目录匹配、同名判断、排除规则和 LOL 特殊处理继续保留。

外部 Discord JSON 和兼容的 SRM Lua 路径都是可选项，普通用户留空即可。旧配置中有效的路径仍按原方式加载；路径缺失或无法读取时回到内置数据。所有既有设置键继续兼容。

## LOL 与 SRM

采集 LOL 客户端时，在游戏所在场景添加一个「窗口采集」源并放在游戏源上方，在「高级设置 → 客户端」选择场景和源，勾选「采集客户端」。默认规则为 `LeagueClientUx.exe=英雄联盟客户端`。对局和其他已识别游戏优先，退出对局后可恢复客户端。

SRM 保存、重命名和整理回放仍为可选功能。由 OGF 自动管理缓存时，请关闭 SRM 的启动时自动开启缓存和保存后重启缓存选项。

## 语言与诊断

默认跟随 OBS，也可手动选择简体中文或 English。源名称、路径和自定义规则保持原样。高级设置和诊断默认收起。

需要排查时，在诊断中点击「3 秒后检查窗口」，切回游戏，再刷新查看结果。检查只读取窗口信息，不修改采集目标。正常启动等待不会再触发脚本日志弹窗，配置错误仍保留提示。

仅支持 Windows 原生游戏、窗口和显示器采集。识别成功不保证所有游戏都能被 OBS 捕获；游戏最小化后也可能停止渲染。
