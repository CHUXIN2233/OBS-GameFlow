# OBS GameFlow

简体中文 · [English](README.md)

自动识别游戏并切换 OBS 采集源，支持桌面录制和回放自动管理。

适用于 Windows 上支持 LuaJIT 脚本的 OBS Studio。运行无需 ASS、Python、WebSocket 或外部常驻程序。

## 安装

1. 解压发布包，把文件放在固定文件夹中。
2. 准备游戏识别数据：运行同目录的 `Update-GameDatabase.ps1` 下载 Discord 游戏库，或使用下方的手动规则、兼容的 SRM Lua 映射。
3. 在 OBS「工具 → 脚本」中添加 `OBS_Game_Follow.lua`。
4. 在要录制的场景中添加一个原生「游戏采集」源，展开脚本的「高级设置」，选中该源并检查游戏库路径。使用 SRM 映射时选择自己的 Lua 文件；不用时清空 SRM 路径。默认路径来自原有配置，请按实际位置调整。
5. 勾选「自动切换」，打开游戏并确认采集正常，再按需开启「自动回放」和「录制桌面」。这三个开关在首次添加脚本时均默认关闭。

已有用户：保留原文件名和路径，替换 `OBS_Game_Follow.lua` 后，在 OBS 原条目中点击「重新加载」。不要同时添加两份脚本，原设置会继续使用。

## 设置

- **自动切换**：跟随正在使用的游戏。Alt+Tab 后保持游戏采集；关闭当前游戏后，恢复仍在运行的其他游戏。
- **自动回放**：自动管理回放缓存。默认关闭，关闭时仍自动切换采集目标，由你手动启停缓存。关闭这个开关不会停止已经运行的缓存。
- **录制桌面**：没有游戏时录制桌面，游戏优先。这项设置决定采集画面，缓存是否自动启停由「自动回放」决定。
- **当前采集 / 回放状态**：显示采集目标与缓存的实际开启、关闭状态。点击「刷新」更新。

开启「自动回放」后的行为：

| 录制桌面 | 缓存管理 |
| --- | --- |
| 关闭 | 检测到游戏时开启；所有游戏退出约 5 秒后关闭。 |
| 开启 | OBS 就绪且桌面采集配置有效后开启；游戏优先，没有游戏时回到桌面。 |

游戏切换、Alt+Tab 和保存回放不会因 OGF 的目标切换而重启缓存。在 OBS「设置 → 输出」中启用回放缓存，并设置保存回放快捷键。停止缓存会丢弃尚未保存的片段。

桌面录制需要把「显示器采集」源加入当前场景，放在游戏和客户端采集源下方，再在「高级设置 → 采集源」中选择。只有一个可用显示器采集源时可自动选择。

## 游戏识别

`Update-GameDatabase.ps1` 从 [Discord 检测列表接口](https://discord.com/api/v9/applications/detectable) 下载 `discord_games.json`，只在手动运行时联网。OBS 脚本只读取本地文件。下载完成后点击「高级设置 → 游戏规则 → 重载游戏库」。不随发布包分发第三方游戏库。

如果系统限制 PowerShell 脚本执行，也可以自行保存该接口的 JSON 到脚本目录，并在「Discord 游戏库」中选中它。该接口可能变化，下载失败时可使用手动规则。

在「补充游戏规则」中每行填写一条：

```text
mygame.exe=我的游戏
```

也可选取本机兼容的 [Smart Replay Mover](https://github.com/SlonickLab/Smart-Replay-Mover) Lua 文件，读取其中内嵌的游戏映射和忽略名单。OGF 不执行或修改 SRM，SRM 也不是必需依赖；不同 SRM 版本的数据格式可能不同。

## LOL 和其他客户端

在游戏所在场景添加一个「窗口采集」源，放在游戏采集源上方。展开「高级设置 → 客户端」，选择所属场景和窗口采集源，勾选「采集客户端」。默认规则为：

```text
LeagueClientUx.exe=英雄联盟客户端
```

脚本会处理 LOL 客户端与对局之间的切换。对局和其他已识别游戏优先于客户端；退出对局后仍可恢复客户端，客户端关闭后按桌面设置处理。

如果同时使用 SRM 保存、整理回放，由 OGF 自动管理缓存时，请关闭 SRM 的启动时自动开启缓存和保存后重启缓存选项。

## 语言与诊断

默认跟随 OBS，也可手动选择简体中文或 English。语言和折叠状态随设置保存。源名称、文件路径和自定义规则保持原样。

「高级设置」和「诊断」默认收起。需要排查时展开诊断，点击「3 秒后检查窗口」后切回游戏，再刷新查看结果。检查只读取窗口信息，不修改采集目标。

仅支持 Windows 原生游戏、窗口和显示器采集。游戏被识别不代表一定能被 OBS 捕获；黑屏或停帧时请检查游戏采集兼容性。游戏最小化后可能停止渲染。
